    Running the export scripts.jsx

    Illustrator

    File › Scripts › Other Script… and pick the file. With a document open, the text lands in the middle of the active artboard; otherwise a new document is made.

    InDesign

    Window › Utilities › Scripts. Right-click the User folder › Reveal in Finder, drop the .jsx in, then double-click it in the panel. The frame auto-sizes to the text and the whole thing is one undo.

    Photoshop

    File › Scripts › Browse…. A new 72 ppi document opens with one editable type layer you can drag into your comp.

    Fonts

    Fonts are matched by family and style name, then by PostScript name. Variable fonts use their named instances (Light, Bold…), so the app shows what the preview shows. Fonts the app can't find are listed and swapped for its default; the text stays editable.

    Distribution

    Ramp sets light → heavy from the start of the text to the end; Ramp per line restarts on every line. Alternate switches between the lighter and heavier half of the pool. Wave has a Period. Weight mix still decides how many letters leave the base style.

    Even gaps

    Where neighbouring letters come from different fonts, their sidebearings differ and the gaps look uneven. Even gaps adjusts the left letter's tracking so the gap moves halfway between the spacing of the two fonts it joins, instead of jumping from one to the other. It exports as tracking.

    Match size

    Different families at the same point size look different sizes. x-height or Cap height scales each letter's font so its lowercase x or capital H is as tall as in the base style (limited to 60–160%). It is written as the letter's point size, so it stays editable; leading follows the nominal size.

    Letter align

    Top, middle and bottom alignment are written as baseline shift values. If you change a letter or its font afterwards, export again to re-align.
